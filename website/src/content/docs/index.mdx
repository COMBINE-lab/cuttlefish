## What Cuttlefish does

Cuttlefish constructs the **compacted de Bruijn graph** — the graph whose
vertices are the maximal unitigs, the non-branching paths of the de Bruijn
graph — from a set of reference sequences or sequencing reads. It is designed
to stay fast and lightweight as the input grows to collection scale.

<CardGrid stagger>
  <Card title="Reads or references" icon="seti:db">
    Build a reference graph from FASTA, or a cutoff-filtered read graph from
    FASTQ. Gzipped input is handled directly.
  </Card>
  <Card title="Colored graphs" icon="seti:pipeline">
    Cuttlefish 3 emits positional colors: which input sources cover which
    stretch of each unitig, written alongside the unitig FASTA.
  </Card>
  <Card title="External memory" icon="laptop">
    Partition buckets, blocked edge matrices, and collation buckets live on
    disk, so peak RAM tracks the worker set rather than the graph.
  </Card>
  <Card title="Parallel throughout" icon="rocket">
    Partitioning, local contraction, discontinuity contraction, and final
    collation all run multi-threaded under a worker budget you set.
  </Card>
</CardGrid>
